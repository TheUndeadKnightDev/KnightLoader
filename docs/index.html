The loader core is fully game-agnostic — the same binary works across Unity Mono games. Raft is the first supported target.

Zero game files touched

Game code is patched in memory only. Uninstalling is deleting four files — your install stays vanilla and update-safe.

Drop-in mods

Mods are single DLLs in a Mods folder, with Harmony 2 included for runtime patching. Drop it in, launch, done.

For developers

A clean API.
A blank canvas.

Spend time building the mod — not fighting the loader. Implement one class, get a full Unity lifecycle (OnLoad, OnUpdate, OnGUI, OnUnload) plus a per-mod Harmony instance and logger.

Unsupported

Check any game in 10 seconds — open its install folder:

  • MonoBleedingEdge\ folder → ✅ stable loader works
  • GameAssembly.dll → 🧪 IL2CPP — experimental bridge
  • a single UnityEngine.dll (no *Module.dll) → ❌ Unity 5.x, too old
  • neither → ❌ not a Unity game

Anti-cheat note: don't use KnightLoader on multiplayer games with EAC/BattlEye active. Mod singleplayer, or servers where mods are allowed.

RESEARCH · EXPERIMENTAL

Beyond Mono.
Into IL2CPP.

IL2CPP games compile C# straight to native machine code — there's no managed assembly to patch, which is why most loaders stop at Mono. We built a bridge anyway. The managed↔native runtime interop is proven working on two games across two Unity generations.

Sons of the ForestUnity 2022.2 · metadata v29bridge verified
Bloons TD 6Unity 6 · metadata v31bridge verified
KnightLoaderIL2CPP.log

UnityEngine.Application class ptr: 0x1F7A061BAF0
>>> RUNTIME INTEROP WORKS <<<
  1. InjectManaged code runs inside the native game via a hosted CoreCLR runtime.
  2. Map the APICpp2IL reconstructs every game type from the il2cpp metadata.
  3. Generate interopIl2CppInterop builds runtime-callable proxies you compile against.
  4. Reach live typesResolve real game classes by name inside the running process.
  5. Full modding APINative Harmony patching + typed mod API + update loop. In progress.

Experimental — not in a public release yet. The Mono loader above is the stable, shipping product. IL2CPP support lives in research until the full API lands.
